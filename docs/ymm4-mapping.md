# YMM4 への配置マニュアル(パック → タイムラインの対応)

このドキュメントは、YMM4 で動画を作る人(「取り込んだらこう並ぶ」を把握したい方)と、
挙動を確認したい開発者向けです。読むと、YMM4 プラグイン「書き庭 台本インポート」
(KakiniwaYmm4Import)が、YMM4受け渡しパック(台本と素材をまとめた受け渡し用フォルダ。
以下、パック)の各イベントを **YMM4 のタイムライン上で何にするか**がわかります。

プラグインの入れ方・使い方は [README](../README.md) を、パックのファイル形式そのものは
別紙「形式仕様」([/docs/pack-format.md](/docs/pack-format.md))を参照してください。
(この形式の正は書き庭側です。リンクはリポジトリ直下からの絶対パスなので、
モノレポでも公開リポジトリでも同じように辿れます)

取り込みの流れ: パックのフォルダを選ぶ → 話者を割り当てる → 「タイムラインへ配置」で、
**いま開いているプロジェクトのタイムラインに項目が一括追加**されます。
元に戻す操作は保証されないため、取り込み前にプロジェクトを保存してください。

## 1. イベント → YMM4 アイテムの対応表

| イベント | YMM4 アイテム | 尺(長さ) | 補足 |
|---|---|---|---|
| `serif`(セリフ) | ボイスアイテム | ボイス生成後の実尺(=生成された音声の実際の長さ) | 割り当て済みキャラなら、YMM4 のセリフ追加と同じ経路で追加され、音声も自動生成されます。`reading` があれば発音(Pronounce)に設定 |
| `serif`(初回の話者) | 立ち絵アイテム(1本) | 原則、最後まで(退場・立ち絵切替で途中終了) | キャラごとに最初のセリフで 1 本だけ置き、以降は表情アイテムで顔だけ切り替えます |
| `serif` の `expression` | 表情アイテム | 対応するボイスの実尺に揃えられます | PSD レイヤーの「全身状態」を丸ごと設定。ボイス側の表情変更は無効化されます(下記) |
| `serif` の `se[]` | 音声アイテム | 音声ファイルの実尺(読めなければ 1 秒) | セリフと同じ開始位置・SE のレーン(レーン=タイムラインの横 1 行のこと。YMM4 でいうレイヤー) |
| `stage`(ト書き) | テキストアイテム(**非表示**) | `seconds`(既定は timing.stageSeconds) | 本文は「(…)」で囲まれ、演出メモとして置かれます。動画には映りません |
| `bg`(背景) | 画像アイテム | 次の `bg` まで | |
| `bgm` | 音声アイテム | 次の `bgm` / `bgm_stop` まで | ループ設定は YMM4 側で調整してください |
| `bgm_stop` | (アイテムなし) | — | 直前の BGM の終端を決めるだけ |
| `se` | 音声アイテム | 音声ファイルの実尺(読めなければ 1 秒) | WAV/MP3/OGG(Vorbis・Opus)はヘッダから実尺を読みます |
| `layout`(立ち位置) | (アイテムなし) | — | 以降の立ち絵の位置・大きさを更新。**配置済みの立ち絵にも即時反映**。`exit: true` は退場=立ち絵アイテムをその時点で打ち切り |
| `window`(テキスト窓) | 画像アイテム | 次の `window_stop` まで | 画面下・幅 95% フィットで仮配置 |
| `prop`(小物) | 画像アイテム | 同じ**素材名**の `prop_stop` まで(無ければ最後まで) | 位置・大きさは `x`/`y`/`height` から計算 |
| `effect` | 画像 or 動画アイテム | `seconds`(0 なら既定 2 秒) | 拡張子が `.mp4` `.webm` `.avi` `.mov` なら動画アイテム |
| `portrait`(立ち絵切替) | (アイテムなし) | — | 現在の立ち絵アイテムを打ち切り、以降のセリフで新しい PSD の立ち絵を置き直します。別の YMM4 キャラを割り当てた立ち絵なら、その間はボイスもそのキャラで生成されます(下記4節) |
| `custom` | (アイテムなし) | — | スキップ(ログにも出ません) |

素材の `path` が null(生成側で見つからなかった)・パック検証に通らない・実在しない場合、
そのイベントは**警告つきでスキップ**され、最後に件数がまとめて表示されます。

## 2. 話者の割り当てとボイス

- パックの各キャラを、YMM4 に登録済みのキャラクターへ**ドロップダウンで割り当て**ます。
  初期選択は「前回の割り当て」→「`ymm4Name`(無ければ `name`)との完全一致」の順で決まります。
  近い名前への推測マッチはしません。
- **割り当て済み**: YMM4 のセリフ追加と同じ内部経路でボイスアイテムが追加され、
  キャラ設定の声で音声が生成されます。立ち絵アイテム・表情アイテムも置かれます。
- **未割り当て**(「名前そのまま」): ボイスは生成されない仮のボイスアイテムに、
  立ち絵はパック内の画像/PSD を画像アイテムで仮置きになります(警告表示あり)。
  取り込み自体は必ず成功します。
- 割り当て済みでも YMM4 側に立ち絵が未設定のキャラは、パックの画像でセリフ区間ごとに
  仮置きされます。
- 本文が空でセリフ内 SE や「間」だけの行は、ボイスアイテムを作りません
  (SE は置かれ、「間」は直前のボイスの後ろに足されます)。
- パックにキャラの声設定(`voice`)があれば、取り込み後のログに
  「声の設定メモ」として表示されます。**YMM4 の声設定への自動反映はしません**
  (手で合わせるための参考情報です)。

## 3. 表情の仕組み

- 表情は**表情アイテム**(立ち絵の顔だけを切り替えるアイテム)で表現します。
  パックの表情の `psd.layers` は「全身の表示レイヤーの完全リスト」で、これを
  キャラ既定の表情パラメータのクローンに設定します。
- レイヤーの内部 ID(`layerIds`)がパックに付いていればそのまま使い、無ければ
  YMM4 の PSD プラグインに問い合わせてパスから解決を試みます。解決できない表情は
  警告つきでスキップされます。
- **ボイスアイテム側の表情変更は取り込み後に無効化**されます。しないと、
  セリフのたびに既定の顔へ戻ってしまうためです。
- 表情アイテムの長さは、配置時は「次の表情変化・退場・末尾まで」で置かれますが、
  実尺での並べ直し(後述)が成功すると**対応するボイスの実尺に揃えられます**。
- 表情指定の無いセリフでは表情アイテムを置きません(直前の表情、または既定の顔のまま)。
- 別機能として「書き庭の表情を YMM4 のプリセットへ登録」ボタンで、パックの表情を
  PSD のプリセット(`<PSD名>-ymm.json`)へ登録できます。複数立ち絵のキャラでは、
  各表情が**属する立ち絵の PSD** のプリセットへ書き分けられます。

## 4. 立ち位置・大きさ(layout)と複数立ち絵(portrait)

- 立ち絵の横位置: `layout` の `x`(画面幅比%・中央 0・負=左)。指定が無いキャラは
  登場順に左(偶数番目)・右(奇数番目)へ、設定の既定オフセット(初期値 ±25%)で振り分けます。
- 高さ: `height`(画面高さ比%)。無ければ設定の既定(初期値 85%)。拡大率は
  「プロジェクトの解像度 × 高さ% ÷ 立ち絵 PSD の実高」で計算します。実高は
  パックの `psdHeight` を優先し、無ければ PSD ヘッダから自分で読みます。
- 縦: 基準は**下端を画面下に揃える**。`y`(正=上)があればそこからずらします
  (YMM4 の Y 座標は正=下なので、プラグインが符号を反転して適用します)。
- `layout` は**配置済みの立ち絵にも即時反映**されます(場面の途中で位置替えできます)。
- `portrait`(立ち絵切替)が来ると、現在の立ち絵アイテムをその時点で打ち切り、
  次のセリフで新しい立ち絵を置き直します。
- **立ち絵ごとの YMM4 キャラ割り当て**(v0.3.0〜): PSD が異なる立ち絵を複数持つキャラは、
  取り込みダイアログに立ち絵ごとの割り当て行が出ます。
  - 「上と同じ」を選ぶと、**立ち絵アイテムのファイルパスを差し替える方式**になります
    (話者・ボイスは主キャラのまま)。`ymm4Name` の指定が無い立ち絵も同じ扱いです。
  - 別の YMM4 キャラを割り当てると、**その立ち絵がアクティブな間は
    ボイス・立ち絵・表情のすべてがその YMM4 キャラで生成されます**。音声の話者も
    変えないと、表情アイテムや口パクの対応が切れてしまうためです。
    初期選択は `ymm4Name` から決まります。
  - 割り当て先が解決できないときは、従来どおり基底のキャラに倒れます。
  - レーン(`voice:<キャラid>`)は**書き庭のキャラ単位のまま**です(割り当て先ごとに
    増えることはありません)。
- `exit: true` の退場は立ち絵アイテムをその時点で終わらせます。以降にまたセリフが
  来れば、新しい立ち絵アイテムで再登場します。

小物(`prop`)・エフェクト(`effect`)の位置は**画面中央原点・正=右/下**で、
`height` は画面高さ比%(小物の既定 25%・エフェクトの既定 100%)です。
立ち絵と y の向きが違うのは意図的な仕様です(入力形式マニュアル参照)。

## 5. レイヤー(レーン)の割り当て

固定の番号表ではなく、**そのパックで実際に使う種類のレーンだけを 0 番から詰めて**
割り当てます。順序(番号が小さい=奥)は:

```
背景 < BGM < SE < ト書き < キャラごとの立ち絵 < 小物 < エフェクト < テキスト窓
  < キャラごとのボイス(字幕) < キャラごとの表情アイテム
```

- 字幕はボイスアイテムのレイヤーに描かれるため、ボイスのレーン自体を窓より手前に
  置いています。さらにテキスト窓があるパックでは、各ボイスの
  「字幕を最前面に表示」も有効化します。
- 表情アイテムは描画を持たない制御アイテムで、**同時刻の表情制御は下の行が勝つ**
  という YMM4 の仕様に合わせて最下段(いちばん大きい番号)に置きます。
- 小物は「時間が重ならない小物は同じレーンに畳む」方式で、入れ替わりの小物が
  レーンを無駄に増やしません。エフェクトは素材名ごとに 1 レーンです。
- 配置先はプラグインの設定で調整できます: **開始レイヤー**(全アイテムをその分だけ
  下の番号へシフト)と**開始位置**(タイムライン先頭 0 秒から/カーソル位置から)。
  設定は次回のために記憶されます。

## 6. 時間計算と衝突解決

パックの `start`/`seconds` は見積りにすぎません。実際の並びは次の手順で決まります。

1. まず見積りどおりの位置に全アイテムを一括追加します。
2. ボイスの音声生成(裏で並行して進む処理)が終わり、**実尺が確定するのを待ちます**
   (最大約 20 秒。半数以上が確定したら先へ進みます)。
3. **ボイスを前から実尺どおりに詰め直します**(先頭のボイスは動かしません)。
   各ボイスの後ろには `timing.serifGap` 秒の間隔と、その行の `pause`(台本の「間」)を足します。
4. ボイス以外のアイテムは、直前のボイスのズレ量ぶん平行移動し、
   「次のイベントまで持続」する背景・BGM・立ち絵・窓・小物は終端も伸縮させます。
   表情アイテムは対応するボイスの実尺に揃えます。
5. 最後のボイスの終端を超えて伸びるアイテムはそこで打ち切ります(末尾の無音防止)。
   音声生成の途中で YMM4 が別レーンへ退避させたアイテムは、意図したレーンへ戻します。
   退場(`prop_stop`)が明示された小物は、次の小物の開始と重ならないよう詰めます。
6. 実尺が揃わず並べ直しを見送った場合のみ、保険として YMM4 の衝突解決
   (重なったアイテムを別レーンへ散らす機能)を呼びます。

この並べ直しは**今回の取り込みで置いたアイテムだけ**が対象です。既存のプロジェクトに
追記しても、置いてあったアイテムは動かされません。同じパックの 2 回目の取り込みも同様です。

## 7. 取り込み時のログと安全確認

取り込み時、ログ欄に次の情報が出ます。困ったときの手がかりにしてください。

- 読み込み結果とバージョンの突き合わせ:
  「書き庭 vX のパック(形式 vN) / プラグイン vY(対応形式 vM)」。
  パックの形式版が新しすぎる場合は**配置せずに停止**し、`pluginMin` を満たさない場合は
  警告して続行します(詳細は入力形式マニュアル)。
- 配置レイヤーの一覧(どのアイテムがどのレーンに置かれたか)。
- スキップした素材の一覧と件数(素材不足・パック外参照など)。
- 動作確認済みの YMM4 版(v4.54 / v4.55)と違う版で実行している場合の注意。

## 8. 注記: 実装と旧仕様メモの食い違い

本書はプラグインの実装(KakiniwaYmm4Import/ 配下のソース)を正として書いています。過去の設計メモ
(書き庭リポジトリの docs/ymm4-bridge.md)と異なる点:

1. **背景(`bg`)は常に画像アイテム**です。旧メモの「拡張子で画像/動画を判定」は
   `effect` のみ実装されており、`bg` に動画を指定しても画像アイテムとして置かれます。
2. **キャラ照合の不一致で中断しません**。旧メモは「不一致は配置前に一覧表示して中断」
   でしたが、実装は割り当て画面とログに警告を出したうえで、仮配置に切り替えて続行します。
3. **表情アイテムの持続**: 旧メモは「次の表情変化・退場・末尾まで持続」ですが、
   実尺での並べ直しが成功した場合、表情アイテムの長さは**対応するボイスの実尺**に
   揃えられます(持続はしません)。並べ直しを見送った場合のみ旧メモどおりの長さが残ります。
4. **レイヤー割り当て**: 旧メモの「0=背景 1=BGM 2=SE 3=ト書き、以降キャラごとに 3 本」
   は固定表ではなく、使う種類のレーンだけを 0 から詰める動的割り当てです(5 章)。
5. **`template`(アイテムテンプレート)**: プラグインは対応済み(serif 以外)ですが、
   現在の書き庭は方針保留のためパックに `template` を出力しません。
6. **timing.stageSeconds の既定**: 旧メモ本文は「既定 1 秒」ですが、パックで省略された
   場合のプラグイン側の既定値は 2 秒です(書き庭は常に明示して出力するため実害はありません)。
7. **layout の `height`**: 旧メモは「null=コンシューマの既定値」ですが、現在の書き庭は
   未指定でもプレビューと同じ既定値を明示して出力します(null 受け入れ自体は残っています)。
