# 翻訳のしかた(日本語・英語以外の言語を足す)

プラグインの**窓の文言**は、日本語・英語・スペイン語(`StringsEs.cs`)が組み込まれています。ほかの言語は、コードを触らずに
JSON ファイルを置くだけで足せます。

## 置き場所とファイル名

プラグインのフォルダ(`<YMM4>\user\plugin\KakiniwaYmm4Import\`)の中に `lang` フォルダを作り、
`<言語コード>.json` を置きます。

```
KakiniwaYmm4Import\
  KakiniwaYmm4Import.dll
  lang\
    ko.json      ← 韓国語の例
```

- 言語コードは英字2〜3文字(`ko` / `zh` / `es` / `pt` など)。YMM4 の表示言語がその言語のとき(自動)、
  または窓の上部の「言語 / Language」でその言語を選んだときに使われます。
- 同じコードが組み込み(`ja` / `en`)にあるときは、書いたキーだけが上書きされます。

## 書き方

中身は `{ "キー": "訳" }` です。**一部だけ訳してかまいません**。訳していないキーは
英語 → 日本語の順で補われます。

```json
{
  "ui.run": "실행",
  "ui.cancel": "취소",
  "ui.place": "3. 타임라인에 배치"
}
```

- キーの一覧と日本語・英語の文言は [`Strings.cs`](../KakiniwaYmm4Import/Strings.cs) の `Ja` / `En` にあります。
  英語の辞書を見ながら訳すのが早いです。
- `{0}` `{1}` は差し込み位置です(バージョン番号や名前が入ります)。**消さずにそのまま**残してください。
  壊れていても窓は落ちず、英語の文言で代用されますが、訳は反映されません。
- 知らないキー・文字列でない値・空の訳は読み飛ばされます。ファイルが 256 KB を超える・JSON として壊れている
  場合は、そのファイルごと無視されます。

## 訳せるもの・訳せないもの

- 訳せる: 窓のボタン・見出し・案内・警告・確認ダイアログ(`Strings.cs` にあるもの全部)。
- 取り込みログのメッセージ(`log.` で始まるキー)も同じ辞書にあり、窓の言語で出ます。
  ★**「」は消さずに残してください**。ログを保存するとき、「」の中(セリフ・名前)を文字数に置き換えて伏せています。
  パス・ファイル名も、言語に関係なく伏せ字になります。
- 訳せない(今は日本語のまま): 伏せ字の印(`<パス>` など)と、保存ログ先頭の一行、YMM4 やパックが返すエラー文。

## 組み込みの言語として足したいとき

`Strings.cs` に辞書(例 `Ko`)を作り、`Tr.Languages` に1行足してプルリクエストを送ってください。
`StringsTests`(キーの揃い・英語に日本語が残っていないこと・差し込み位置の数)が見張っています。
