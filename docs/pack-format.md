# YMM4受け渡しパック 形式仕様(timeline.json v1)

**この文書がこの形式の正です。**「YMM4受け渡しパック」は書き庭が定める受け渡し規格で、
書き出す側(書き庭・自作ツール)も読む側(YMM4 プラグイン)も、ここに書いてあることに従います。
実装が食い違っていたら、直すのは実装の側です。

契約は文章だけでなく、**黄金ファイル `fixtures/timeline.golden.json`** で機械的にも
縛ってあります。書き出す側(書き庭の TypeScript)と読む側(プラグインの C#)が同じファイルを
読んで検証するので、**片側だけ変えるとテストが落ちます**。仕様を変えるときは、この
ファイルと両側のテストも一緒に変えてください。

> 置き場所はリポジトリによって違います。プラグインの公開リポジトリでは
> リポジトリ直下の `fixtures/`、書き庭のモノレポでは ymm4-plugin フォルダの下の
> 同名のフォルダです(同じファイルが同期されています)。

> この文書は YMM4 プラグインの公開リポジトリへも `docs/pack-format.md` として配られます。
> 写しの方を編集しても次の同期で消えます。直すときは書き庭側(モノレポの `docs/`)で。

このドキュメントは、パックを自作したい外部ツールの開発者と、形式の詳細を知りたい方向けです。
読むと、YMM4 プラグイン「書き庭 台本インポート」(KakiniwaYmm4Import)が読み込む
入力形式「YMM4受け渡しパック」を、自分のツールから書き出せるようになります。
JSON が読めれば追える内容です。

パック(以下、受け渡しパックを指します)は通常、台本エディタ「書き庭」が書き出しますが、
形式は書き庭に依存しません。**この形式でパックを作れば、どんなツールからでも
YMM4 のタイムラインへ取り込めます。**

プラグイン自体の入れ方・使い方はプラグインの README を、プラグインが各イベントを
YMM4 のどのアイテムにするかは「YMM4 への配置マニュアル」(プラグイン側の
`docs/ymm4-mapping.md`)を参照してください。
※この2つはプラグイン側の文書です。相対リンクを張らないのは、この文書がモノレポと
公開リポジトリの両方に置かれ、両者で位置関係が違うためです。

## 1. パックの構造

パックは 1 つのフォルダです。プラグインの「受け渡しパックのフォルダを選ぶ」で
このフォルダを指定します。

```
<任意の名前>/
  timeline.json        ← 必須。本書が定義する中間ファイル
  assets/              ← 素材を同梱する場合のみ(構成は自由。timeline.json のパスと合っていればよい)
    backgrounds/…
    bgm/…  se/…
    portraits/<キャラid>/…
  (その他のファイル)    ← 任意。マニフェストやクレジットなど。プラグインは読みません
```

- プラグインが読むのは `timeline.json` と、そこから参照される素材ファイルだけです。
- フォルダ名・素材フォルダの構成に決まりはありません。timeline.json に書いたパスと
  実ファイルが一致していれば取り込めます。

## 2. ファイル規約

- **JSON・UTF-8(BOMなし)**。人が読めるよう、整形(2スペースインデント)と
  日本語の非エスケープ出力を推奨します(必須ではありません)。
- フィールド名は **camelCase**(=`charsPerSecond` のように、2 語目以降の頭を大文字にするつなぎ方)。
  プラグイン側の読み取りは大文字小文字を区別しません。
- **未知のフィールドは無視されます。** 独自フィールドを足しても取り込みは壊れません。
- 時間はすべて **秒(小数)** で持ちます。フレーム換算は、プロジェクトの FPS を知っている
  プラグイン側が行います。

## 3. バージョンと互換ポリシー(formatVersion=形式の版数のこと)

形式の版数(formatVersion)は、timeline.json では `version` フィールドで表します。

| フィールド | 型 | 必須 | 意味 | 例 |
|---|---|---|---|---|
| `version` | number | ○ | 形式の版。現在は `1` のみ | `1` |
| `pluginMin` | string | 任意 | このパックを正しく読むのに必要なプラグインの最低版 | `"0.2.2"` |
| `pluginLatest` | string | 任意 | パックを書き出したツールが知っている最新プラグイン版(更新案内用) | `"0.2.4"` |

プラグインの挙動:

- **`version` が自分の対応版(現在 1)より大きいパックは、配置せずに停止**し、
  プラグインの入れ替えを案内します。知らない形式を旧版と思い込んで黙って誤配置しない、
  という安全策です。
- `version` が無い(0 以下)場合は「形式版がありません」と注意を出しつつ、読める範囲で読みます。
- `pluginMin` がプラグイン自身の版より新しい場合は、**警告を出したうえで続行**します
  (正しく読めない項目がある可能性の告知)。
- `pluginMin` は満たすが `pluginLatest` の方が新しい場合は、新版の案内だけをログに出します。
  どちらも**外部への通信は行わず**、パックに書かれた情報だけで判断します。
- 版の比較は `"0.2.1"` のようなドット区切りの数値比較です。数値でない部分は 0 扱いになります。

新しいフィールドの**追加**では `version` は上がりません(未知フィールドは無視されるため)。
既存フィールドの意味や型を変える破壊的変更のときだけ上がります。

## 4. セキュリティ上の制約(素材パスの扱い)

パックは第三者から受け取ることもあるため、プラグインは素材パスを次のルールで検証します。
自作ツールもこのルールに合うパスを出力してください。

- **パック内相対パス**(推奨・素材同梱時): パックフォルダと結合して正規化した結果が
  **パックフォルダ配下であること**が必須です。`../` などでパックの外へ出るパスは拒否されます。
- **絶対パス**(素材を同梱しない場合): ローカルドライブ(`C:\` 等)のパスのみ許可されます。
  さらに**素材として意味のある拡張子だけ**が許可されます:
  - 画像: `.png` `.jpg` `.jpeg` `.webp` `.bmp` `.gif` `.avif`
  - 音声: `.wav` `.mp3` `.ogg` `.flac` `.m4a` `.aac` `.opus`
  - 動画: `.mp4` `.webm` `.mov` `.avi` `.mkv`
  - 立ち絵: `.psd`
- **UNC パス(`\\server\…`)とデバイスパスは常に拒否**されます(存在確認すら行いません。
  細工されたパックが、閲覧しただけで認証情報を外部へ送らせるのを防ぐため)。
- 検証に通らないパス・実在しないファイルは、そのイベントを警告つきでスキップします
  (取り込み全体は止まりません)。

## 5. トップレベル

| フィールド | 型 | 必須 | 意味 | 例 |
|---|---|---|---|---|
| `version` | number | ○ | 形式版(前章) | `1` |
| `generator` | object | 任意 | 生成元の記録 `{ "name": …, "version": … }`。ログ表示に使用 | `{ "name": "書き庭", "version": "0.6.0" }` |
| `pluginMin` | string | 任意 | 前章 | `"0.2.2"` |
| `pluginLatest` | string | 任意 | 前章 | `"0.2.4"` |
| `title` | string | ○ | 作品タイトル(ログ表示用) | `"つばめ珈琲"` |
| `episode` | string | ○ | 話タイトル(ログ表示用) | `"朝のつばめ"` |
| `timing` | object | ○ | 尺の見積りに使った定数(下記) | |
| `characters` | array | ○ | 登場キャラ(下記)。空配列も可 | |
| `events` | array | ○ | タイムライン要素・台本の出現順(下記) | |

`timing`(いずれも number):

| フィールド | 必須 | 意味 | 既定(省略時) |
|---|---|---|---|
| `charsPerSecond` | 任意 | セリフ尺の見積りに使った文字数/秒 | 6 |
| `serifGap` | 任意 | セリフとセリフの間に置く間隔(秒)。**実尺(=生成されたボイスの実際の長さ)での再配置にも使われます** | 0.2 |
| `stageSeconds` | 任意 | ト書きの表示尺(秒)。時間の進行には影響しません | 2 |

## 6. characters[] — 登場キャラ 1 件

| フィールド | 型 | 必須 | 意味 | 例 |
|---|---|---|---|---|
| `id` | string | ○ | パック内でキャラを指す id。events の `speaker` が参照 | `"sora"` |
| `name` | string | ○ | 表示名 | `"ソラ"` |
| `ymm4Name` | string \| null | 任意 | YMM4 のキャラクター設定の登録名(**完全一致**で照合)。null なら `name` で照合 | `"つばめソラ"` |
| `portraitDir` | string \| null | 任意 | 立ち絵フォルダのパス(表情の `file` の基準)。素材が無ければ null | `"assets/portraits/sora"` |
| `expressions` | array | ○ | 表情プリセット(下記)。空配列も可。**立ち絵ごとの表情も、この配列に合流させて入れてください**(プラグインの「表情をプリセットへ登録」等は両方から集めますが、flat 側が正です) | |
| `portraits` | array | 任意 | 複数立ち絵(別 PSD への切替単位・下記)。1 枚だけのキャラでは省略 | |
| `voice` | object | 任意 | 生成元ツール側の声設定(**参考情報**)。`{ "engine": string, "preset": string \| null, "params": { 名前: 数値 } }`。YMM4 の声設定には自動反映されず、ログの案内にだけ使われます。`params` の値は**数値のみ**(文字列が混ざるとパック全体の読み込みが失敗します) | |

`expressions[]` の 1 件:

| フィールド | 型 | 必須 | 意味 | 例 |
|---|---|---|---|---|
| `id` | string | ○ | 表情タグ。events の `expression` はこの `id` か `label` を指す | `"ドヤ"` |
| `label` | string \| null | 任意 | 表示名(id と別表記がある場合)。プリセット登録名は label 優先 | `null` |
| `default` | boolean | 任意 | 既定の表情か(表情指定の無いセリフで使う) | `true` |
| `file` | string \| null | 任意 | 画像 1 枚方式のファイル名(`portraitDir` からの相対) | `"doya.png"` |
| `psd` | object \| null | 任意 | PSD 立ち絵方式(下記) | |

`psd` オブジェクト:

| フィールド | 型 | 必須 | 意味 |
|---|---|---|---|
| `path` | string | ○ | PSD ファイルのパス(相対=パック内 / 絶対=フルパス参照。4章の制約に従う) |
| `layers` | array of string | ○ | 表示するレイヤーの**全身の完全リスト**(差分ではありません)。各要素は `/` 区切りのレイヤーパス(例 `"体/顔/目/にっこり"`)。部分リストを渡すとキャラ全体が消えます |
| `layerIds` | array of number | 任意 | `layers` と**同順・同数**の YMM4 内部レイヤーID(`nXXX` の数値部)。ID は「PSD の生レコード順の通し番号(0起点)」です。省略時はプラグインが YMM4 の PSD プラグイン経由でパス解決を試みますが、付けた方が確実です |

`portraits[]` の 1 件(複数立ち絵キャラのみ):

| フィールド | 型 | 必須 | 意味 |
|---|---|---|---|
| `id` | string | ○ | 立ち絵 id。`type:"portrait"` イベントの `name` が参照します。**イベント側は必ずこの id で書いてください**(表示名のままだと切替が効かないことがあります) |
| `default` | boolean | 任意 | 既定の立ち絵か(true が無ければ先頭が既定) |
| `ymm4Name` | string \| null | 任意 | この立ち絵を割り当てる別の YMM4 キャラ名。null なら主キャラのまま PSD だけ差し替え |
| `psd` | object \| null | 任意 | 立ち絵のベース PSD(形式は上の `psd` と同じ) |
| `file` | string \| null | 任意 | 非 PSD の一枚絵(`portraitDir` からの相対) |
| `expressions` | array | ○ | この立ち絵の表情(形式は `expressions[]` と同じ)。空配列も可 |

## 7. events[] — タイムライン要素 1 件

イベントは台本の出現順に並べます。共通フィールド:

| フィールド | 型 | 必須 | 意味 | 例 |
|---|---|---|---|---|
| `no` | number | ○ | 通し番号(1起点)。警告表示に使用 | `3` |
| `scene` | string | ○ | 所属シーン名。無ければ `""` | `"朝のつばめ"` |
| `type` | string | ○ | イベント種別(下記) | `"serif"` |
| `start` | number | ○ | 先頭からの累積秒。**参考値**です(プラグインはボイスの実尺で並べ直します)。負値・非数は 0 に丸められます | `5.2` |
| `seconds` | number | ○ | 見積り尺(秒)。serif=見積り、stage=表示尺、それ以外=0 | `1.7` |

種別ごとの追加フィールド:

| type | 意味 | 追加フィールド |
|---|---|---|
| `serif` | セリフ | `speaker`(string \| null: キャラ id。未登録話者は null)、`speakerName`(string \| null: 表示名。未登録でも台本の表記)、`expression`(string \| null: 表情タグ。null=既定表情)、`text`(string: 本文。空なら「SE・間だけの行」)、`reading`(string \| null: 読み上げ用テキスト。本文と同じなら null)、`se`(array: セリフ内効果音の素材参照の配列)、`pause`(number・任意: この行に書かれた「間」の合計秒。実尺再配置のとき、ボイスの後ろに足されます) |
| `stage` | ト書き(演出メモ) | `text`(string) |
| `bg` | 背景の切替 | `asset`(素材参照) |
| `bgm` | BGM 開始 | `asset` |
| `bgm_stop` | BGM 停止 | なし(直前の `bgm` の終端を決めるだけ) |
| `se` | 単発の効果音 | `asset` |
| `layout` | 立ち位置の指定(以降に適用) | `positions`(array・下記) |
| `window` | テキストウィンドウ画像の表示 | `asset` |
| `window_stop` | ウィンドウの終了 | なし |
| `prop` | 小物・前景画像の表示 | `asset`、`x`/`y`/`height`(number・任意・%) |
| `prop_stop` | 小物の終了 | `name`(string: 対象の**素材名**。`prop` 側の `asset.name` と一致させる) |
| `effect` | 短時間オーバーレイ(画像/GIF/動画) | `asset`、`x`/`y`/`height`(任意)、`seconds`(0 なら既定 2 秒) |
| `portrait` | 立ち絵の切替(以降に適用) | `speaker`(キャラ id)、`name`(切替先の**立ち絵 id**) |
| `custom` | 機械処理対象外のコマンド | `name`/`arg`(string)。プラグインはスキップします |

未知の `type` は警告つきでスキップされます(取り込みは続行)。

素材参照オブジェクト(`asset` および `se[]` の要素):

| フィールド | 型 | 必須 | 意味 |
|---|---|---|---|
| `name` | string | ○ | 素材の表示名。`prop` ↔ `prop_stop` の対応づけにも使われます |
| `path` | string \| null | ○ | 素材ファイルのパス(4章の制約に従う)。**null は「素材不足」の印**で、そのイベントは警告つきでスキップされます |

`positions[]` の 1 件(`layout` のみ):

| フィールド | 型 | 必須 | 意味 |
|---|---|---|---|
| `speaker` | string | ○ | キャラ id |
| `x` | number | ○ | 画面中央からの横位置(画面幅比%・-50〜50・負=左) |
| `y` | number | 任意 | 縦オフセット(画面高さ比%・**正=上**・下端揃え基準)。省略=下端揃えのまま |
| `height` | number \| null | 任意 | 立ち絵の高さ(画面高さ比%)。null/省略=プラグインの既定値(初期値 85%) |
| `psdHeight` | number | 任意 | いま出ている立ち絵 PSD の実高(px)。あると、立ち絵切替後も正しい拡大率を計算できます(拡大率そのものは解像度依存のため渡しません) |
| `exit` | boolean | 任意 | true で退場(立ち絵をこの時点で終える。以降にセリフが来れば再登場) |

### 座標系の注意(y の意味が type で違います)

- `layout` の `y`: **下端揃え基準・正=上**(立ち絵は画面下端に立つのが基準のため)
- `prop` / `effect` の `x`/`y`: **画面中央原点・正=右/下**(前景は中央に置くのが基準のため)

これは意図的な違いで、プラグインが `layout` 側だけ符号を反転して YMM4 座標(正=下)へ
変換しています。`x` はどちらも中央原点・正=右で共通です。

### 時間の考え方

- `start`/`seconds` は見積りです。プラグインは配置後、**ボイスの実尺で前から詰め直す**ため、
  見積りが多少ずれても構いません。ただしイベントの**順序**と、同時に起きるものの
  **start の一致**(例: セリフとその行の SE は同じ start)は意味を持ちます。
- ト書き(`stage`)は時間を消費しません。`start` には「直後のセリフの開始」を入れるのが慣例です。
- セリフ中の「間(溜め)」は `seconds` に織り込んだうえで、**`pause` にも別途**入れてください。
  実尺での並べ直しの際、見積り尺は捨てられるため、`pause` が無いと間が消えます。
- `text` が空(空白のみ)の `serif` はボイスになりません。`se` や `pause` だけを運ぶ行として使えます
- `text` には改行が入ることがあります(台本の `[改行]`)。字幕を2行で見せるための折り返しで、声には出ません。そのため改行のある行では `reading`(改行を含まない読み)が必ず入ります
  (`pause` は直前のボイスの後ろに足されます)。

## 9. 手書き・自作ツール向けの許容範囲

プラグインは壊れかけのパックにもある程度耐えます(ただし頼らないでください):

- `events` / `characters` / `timing` が `null` → 空扱いで続行
- 配列内の `null` 要素 → 除去
- `start` / `seconds` の負値・NaN・Infinity → 0 に丸め
- `type` が `null` → 空文字扱い(未知 type としてスキップ)

一方、**型の不一致は致命的**です(例: `voice.params` に文字列値)。JSON 全体の
デシリアライズ(=JSON テキストをプログラムのデータに変換する処理)が失敗し、
パックが丸ごと読めなくなります。

## 10. 決めごとの補足(過去の設計メモとの差)

書き庭側に残っている以前の設計メモ(モノレポの `docs/ymm4-bridge.md`・`ymm4-notes.md`。
プラグインの公開リポジトリには同期していません)には、ここと違う記述があります。
**仕様としてはこの文書が正**なので、下を採ります。

- **`template`(YMM4 アイテムテンプレート名)**: 形式としては存在し、プラグインは読み取って
  適用を試みます(bg/bgm/se/stage/window/prop/effect のみ。serif は未対応)。
  ただし書き庭は方針保留のため **`template` を出力しません**。
  自作ツールが出力するのは自由ですが、挙動は実験的です。
- **レイヤー(レーン)の割り当ては固定表ではありません**。「0=背景 1=BGM 2=SE 3=ト書き…」の
  ような固定割り当てはせず、**実際に使う種類のレーンだけを 0 から詰めて**割り当てます。
- **キャラ照合が一致しなくても中断しません**。警告つきで仮配置へフォールバック
  (=うまくいかないときの代替動作に切り替えること)します。取り込み自体は必ず成功します。
